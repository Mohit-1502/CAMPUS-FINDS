# Campus Finds

A mobile-friendly lost and found board for a college campus.

## Preview

Open `index.html` in a browser. Reporting, search, filters, contact links, and reunited status work in the browser. Listings are saved locally in that browser.

## Install as an app

This is a Progressive Web App (PWA). It needs to be served from a secure site (`https://`) or `localhost`; opening the file directly with `file://` is only a preview and cannot activate offline/install support. After hosting it on HTTPS, open the site on your phone:

- **Android:** In Chrome, choose **Install app** or **Add to Home screen**.
- **iPhone:** In Safari, use **Share → Add to Home Screen**.

The app shell is cached after the first visit, so it can reopen offline. Listings still live only in the browser/device where they were posted. Connect a shared database before using it campus-wide. This project is an installable web app, not an app-store package.

The board starts with sample listings; sample contact details are placeholders.
